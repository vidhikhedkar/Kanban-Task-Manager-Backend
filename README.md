🚀 Kanban Task Manager Backend
A secure RESTful backend API for a Kanban Task Management application built with Node.js, Express.js, MongoDB, and Mongoose. It provides user authentication, protected routes, task management, and secure cookie-based JWT authentication.

✨ Features
User Registration & Login
Secure JWT Authentication
HTTP-Only Cookie-based Session Management
Password Hashing using bcrypt
Change Password Functionality
User Profile API
Protected Routes with Authentication Middleware
Complete CRUD Operations for Tasks
User-specific Task Management
MongoDB Database Integration
RESTful API Architecture
Environment Variable Configuration
CORS & Cookie Parser Support
